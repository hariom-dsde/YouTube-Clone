# 📺 YouTube Clone

This is a simple front-end clone of YouTube built using **HTML** and **CSS**. The project replicates the layout and styling of the YouTube homepage, featuring responsive design principles and UI components like thumbnails, icons, and a sidebar.

---

## 🗂️ Project Structure

```
.
├── channel-pictures/    # Channel profile images
├── icons/               # UI icons (menu, search, etc.)
├── intro-to-html/       # Additional HTML examples or notes
├── styles/              # CSS files
├── thumbnails/          # Video thumbnail images
├── flexbox.html         # Flexbox layout practice
├── grid.html            # CSS Grid layout practice
├── youtube.html         # Main YouTube clone page
└── desktop.ini          # System file (can be ignored)
```

---

## 🌐 Live Preview

To view the clone:

1. Download or clone the repository.
2. Open `youtube.html` in any modern web browser.

---

## 🚀 Features

* Responsive layout using **Flexbox** and **CSS Grid**
* Sidebar navigation with icons
* Video thumbnails with titles and channel info
* Custom profile and channel images
* Simulated YouTube UI using static HTML & CSS

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox & Grid)

---

## 📁 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/thepunyagarg/youtube-clone.git
   ```
2. Navigate to the project directory.
3. Open `youtube.html` in your browser to view the page.
